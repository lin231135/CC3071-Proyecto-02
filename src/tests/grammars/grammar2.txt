# Gramática 2 — No terminales anulables (epsilon)
# Complejidad: media-alta
# Ejercita la propagación de ε en PRIMERO y SIGUIENTE.
#
# PRIMERO esperado:
#   S = { a, b, c }
#   A = { a, ε }
#   B = { b, ε }
#   C = { c }
#
# SIGUIENTE esperado:
#   S = { $ }
#   A = { b, c }
#   B = { c }
#   C = { $ }

S -> A B C
A -> a | epsilon
B -> b | epsilon
C -> c
