Gramática 1 — Expresiones aritméticas (Libro del Dragón §4.28)
Complejidad: media

E -> E PLUS T | T
T -> T TIMES F | F
F -> LPAREN E RPAREN | ID

PRIMERO esperado:
    E = { ID, LPAREN }
    T = { ID, LPAREN }
    F = { ID, LPAREN }

SIGUIENTE esperado:
    E = { $, PLUS, RPAREN }
    T = { $, PLUS, RPAREN, TIMES }
    F = { $, PLUS, RPAREN, TIMES }

Gramática 2 — No terminales anulables (epsilon)
Complejidad: media-alta

S -> A B C
A -> a | epsilon
B -> b | epsilon
C -> c

PRIMERO esperado:
    S = { a, b, c }
    A = { a, ε }
    B = { b, ε }
    C = { c }

SIGUIENTE esperado:
    S = { $ }
    A = { b, c }
    B = { c }
    C = { $ }

------------------------------------------------------------------------

Gramática 3 — Sentencias con else opcional
Complejidad: alta

Nótese que la recursión izquierda en stmtlist hace que {IF, ID} se propaguen a los SIGUIENTE de casi todos los no terminales.

stmtlist   -> stmtlist stmt | stmt
stmt       -> IF expr THEN stmt elseclause | ID ASSIGN expr
elseclause -> ELSE stmt | epsilon
expr       -> ID


PRIMERO esperado:
    stmtlist   = { ID, IF }
    stmt       = { ID, IF }
    elseclause = { ELSE, ε }
    expr       = { ID }

 SIGUIENTE esperado:
    stmtlist   = { $, ID, IF }
    stmt       = { $, ELSE, ID, IF }
    elseclause = { $, ELSE, ID, IF }
    expr       = { $, ELSE, ID, IF, THEN }
